# Salem 0.3.0 — validación de la distribución

Estado: candidata en validación; esta página se actualizará con los resultados finales antes de publicar un release.

Esta versión incorpora configuración editable de modelos, un perfil inicial Opus5.5 Medio/Sol, distribución Windows por usuario y documentación para la comunidad. Conserva aceptación por checks reales y revisión independiente, capacidades explícitas y recuperación persistente.

## Recorridos de aceptación

La validación automatizada y las pruebas con cuentas reales se registran por separado. Los resultados pendientes no se cuentan como aprobados. Los recibos privados, rutas personales y credenciales no se publican.

## Límites

- El instalador inicial no tiene firma digital. Windows x64 es la plataforma de esta distribución; macOS/Linux no están acreditados.
- La disponibilidad de modelos depende de la cuenta, cliente y organización. Autenticación correcta no implica acceso a cada modelo.
- El reparto de modelos se configura por etapa. No se atribuye ahorro o superioridad universal a los presets.
- Los agentes y checks usan el usuario local; no hay una sandbox de sistema operativo para código hostil.
- La autoevolución aplica código fuente aceptado con respaldo, sin sustituir el runtime instalado ni cambiar verificadores o permisos. No monitoriza continuamente regresiones futuras.
- La aceptación del demo no equivale a un piloto de producción ni autoriza acciones en otros productos.
