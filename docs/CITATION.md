## Próximas versiones

Actualiza versión, fecha y commit en `CITATION.cff` para cada versión publicada.
Mantén la autoría y el ORCID según las contribuciones reales. Archiva el código
fuente con su licencia y sus avisos de terceros, y enlaza la release de GitHub.
Comprueba archivos, metadatos y visibilidad antes de publicar en Zenodo. Tras la
publicación, verifica que el DOI resuelve al registro correcto y actualiza `doi`
y `url` con el DOI y el registro canónico de esa versión. No incorpores un DOI
reservado como si ya estuviera publicado. Añade o actualiza la misma obra en ORCID.

GitHub muestra la opción **Cite this repository** cuando el archivo está en la
rama predeterminada.

Zenodo puede archivar nuevas releases automáticamente una vez habilitado el
repositorio. `CITATION.cff` es la fuente de metadatos para ese flujo; si se agrega
también `.zenodo.json`, Zenodo da prioridad a ese JSON e ignora el CFF. Evita
mantener dos fuentes distintas sin una necesidad concreta.
