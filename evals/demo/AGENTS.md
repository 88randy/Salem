# Demo de evaluación

implementar. No editar AGENTS.md, tests o configuración; no usar Git, red ni
publicar cambios. El controlador verifica y entrega. En define/review solo leer.
No instalar paquetes. Módulos ESM puros en Node.js; números finitos en estas tareas.
Reportar findings honestos; success sin código verificado no acredita aceptación.
